## Страны, сезоны, визы и дайвинг

Файл: [`data/destinations.json`](./data/destinations.json)

### Массив `months`

Названия месяцев для календаря и таблицы (12 элементов, порядок: январь → декабрь).

### Массив `destinations`

Каждое направление — объект:

| Поле | Назначение |
|------|------------|
| `id` | Уникальный идентификатор (латиница, без пробелов) |
| `name` | Название направления |
| `region` | Регион (группировка в фильтрах) |
| `airport` | Аэропорт |
| `visa` | Визовый режим: `Б` (без визы) или `П` (по прибытии) |
| `diving` | Уровень дайвинга: `Развитая`, `Есть` или `Ограниченная` |
| `season` | Массив индексов месяцев (0 = январь, 11 = декабрь), когда сезон |
| `temperature` | Температура (строка, например `"воздух +28°C, вода +26°C"`) или `null` |
| `description` | Описание направления |
| `flights` | Массив типичных маршрутов |
| `budget` | Бюджетная метка |
| `priceFrom` | Ориентир цены |

### Блок `visaLabels`

Подписи для визовых кодов `Б` и `П` (`short` — для бейджей, `long` — для таблицы).

### Блок `ui`

Подписи фильтров, заголовков таблицы, плейсхолдеров и прочих элементов интерфейса. Редактируйте здесь, если нужно изменить текст кнопок и подсказок без правки кода.

## Проверка визовых условий

Каталог направлений в [`data/destinations.json`](./data/destinations.json) — **курируемая туристическая подборка** для планирования отдыха. Это не полный список стран и территорий, доступных гражданам Беларуси, и не замена официальным консульским источникам.

### Файл аудита

Таблица для поэтапной проверки виз: [`data/visa-audit.csv`](./data/visa-audit.csv).

| Колонка | Назначение |
|---------|------------|
| `destination` | Название записи в каталоге (как в `destinations.json`) |
| `country_or_territory` | Государство или территория для сверки правил въезда |
| `current_visa_code` | Текущий код в данных (`Б` или `П`) — **не менять без проверки** |
| `proposed_visa_type` | Целевой тип после проверки (заполняется только по источнику) |
| `visa_note` | Уточнение: остров, регион, курорт и т.п. |
| `visa_checked_at` | Дата проверки (ISO, например `2026-08-08`) |
| `visa_source_url` | Ссылка на официальный источник |
| `verification_status` | Статус: `unverified`, `verified`, `disputed` |

### Правила работы с визами

1. **Статусы нельзя менять без источника.** Поле `visa` в `destinations.json` и коды в интерфейсе обновляются только после сверки с официальным источником (консульство, MFA, пограничная служба принимающей страны).
2. **У каждой проверенной записи** в `visa-audit.csv` должны быть заполнены `visa_checked_at` и `visa_source_url`, а `verification_status` — `verified`.
3. **Не делайте предположений** в колонке `proposed_visa_type`: если источник не найден, оставляйте поле пустым и статус `unverified`.
4. Условия въезда зависят от срока поездки, цели, маршрута и транзита — это отражено в предупреждении на сайте, но не заменяет индивидуальную проверку перед бронированием.
