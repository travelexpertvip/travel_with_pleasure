# Сбор публичных туров

Workflow `.github/workflows/import-tours.yml` запускается каждые шесть часов и может быть запущен вручную через GitHub Actions. Он читает веб-предпросмотр публичных Telegram-каналов и создаёт либо обновляет один draft PR с файлами в `docs/.vitepress/content/tour-drafts/`.

## Источники

Список каналов находится в `config/tour_sources.json`:

- `@LTCB2B`
- `@toursmsk`
- `@rosting`
- `@Anywaytravelminsk`

## Безопасность публикации

Собранные файлы не отображаются на сайте: загрузчик карточек читает только `.vitepress/content/tours/*.md`. Каждый найденный пост создаётся со статусом `draft`.

Перед ручным переносом карточки в опубликованный каталог необходимо проверить безвизовость для паспорта Беларуси, страну, даты, количество ночей, отель, питание, цену за двоих и ссылку на исходный пост.

## Ограничения

Парсер использует эвристики для определения города вылета, ночей, звёздности и питания. Он исключает Египет, Турцию и Болгарию, но не заменяет ручную проверку визовых требований и деталей предложения.
