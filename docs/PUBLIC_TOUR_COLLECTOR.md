# Сбор публичных туров

Workflow запускается каждые шесть часов и создаёт либо обновляет draft PR. Для одного Telegram-поста с несколькими отелями импортёр создаёт отдельный Markdown-файл на каждый отель в `docs/.vitepress/content/tours/`.

Все отели из одного поста имеют общий `offer_group_id`, поэтому интерфейс объединяет их в одно предложение. Новые записи получают `status: draft` и не показываются на сайте: загрузчик VitePress передаёт в интерфейс только карточки со `status: active`.

## Ручная публикация

В draft PR проверьте визу для паспорта Беларуси, цену, даты и условия. Для выбранных карточек замените `status: draft` на `status: active`, затем сделайте merge PR в `main`. Не нужно переносить файлы между каталогами.

## Спецпредложения

Если в исходном тексте явно присутствует срок действия акции в формате `до DD.MM.YYYY` или `по DD.MM.YYYY`, импортёр задаёт `offer_type: special` и заполняет `special_offer_valid_until`. При отсутствии явного срока используется `offer_type: standard`.
